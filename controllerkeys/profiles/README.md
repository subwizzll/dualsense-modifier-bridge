# ControllerKeys profiles

Put exported ControllerKeys profile `.json` files in this folder.

## Export from this Mac
1. Open **ControllerKeys**
2. Select your DualSense profile
3. Use **Import Profile...** sibling action: **Export Profile** (profile menu / sidebar)
4. Save the `.json` into this directory, e.g. `DualSense Modifiers.json`

## Import on another Mac
1. Install ControllerKeys
2. **Import Profile...** and choose the `.json` from this folder
3. Confirm hold-modifiers are set (defaults that match the Hammerspoon bridge):
   - **RT** → ⌘ hold
   - **LB** → ⌥ hold
   - **RB** → ⌃ hold
   - (optional) **Share** → ⌘⌥ hold
